# Практическое задание №1

ИКБО-71-24, вариант 12.

Программа хранит в памяти записи `Entity`, `Command` и `Result`.

## Этап 1

В `src/main.py` реализованы создание, чтение и изменение записей, выборка
команд для сущностей за последние шесть минут и простой REPL.

Запуск:

```console
run.bat repl
```

Команды REPL совпадают с именами функций. Для выхода используется `exit`.

## Этап 2

В том же файле находится TCP RPC-сервер и класс `RpcClient`. Сервер передаёт
JSON с заголовками из задания и выводит каждый ответ в консоль.

```console
run.bat server
run.bat demo
```

Демонстрация вызывает через TCP все десять функций модели.

Сначала запустите сервер, затем демонстрацию в другом терминале.

## Этап 3

Тестирование RPC выполнено с помощью `RuleBasedStateMachine` из Hypothesis.

```console
python -m pip install -r requirements.txt
run.bat test
```

Команда запускает сгенерированные тесты, выводит покрытие ветвей и проверяет
PEP 8.
